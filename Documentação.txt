__________________________________________________________________________

Projeto de Teste — Laravel + Vue 3 + Vuetify. Este projeto foi criado 
para fins de estudo e testes práticos de integração entre back-end 
Laravel e front-end Vue.js com a biblioteca Vuetify.
__________________________________________________________________________

Back-end
   - Laravel: v10.48.29
   - PHP: v8.3.23 (Docker) / v8.4.1 (máquina local)
   - PostgreSQL: v15.14
   - Nginx: v1.29.0 (Docker)
__________________________________________________________________________

Front-end
   - Vue.js: v3.5.17
   - Vuetify: v3.5.10 (Interface moderna baseada no Material Design.)
   - Inertia.js (integração entre Laravel e Vue.js)
   - Vite (bundler moderno para desenvolvimento)
__________________________________________________________________________

Dependências do Projeto
   - devDependencies
      + "@vitejs/plugin-vue": "^6.0.0"       <- plugin oficial para que o Vite entenda arquivos .vue
      + "laravel-vite-plugin": "^1.3.0"      <- integração entre Laravel e Vite (resolve imports, hot reload, build de assets)
      + "sass": "^1.89.2"                    <- pré-processador CSS para usar .scss/.sass com funcionalidades extras como variáveis
      + "sass-loader": "^16.0.5"             <- permite que o Vite (via Webpack) entenda arquivos .scss e processe com o sass
      + "vite": "^6.3.5"                     <- empacotador moderno e ultrarrápido que substitui o Webpack no Laravel 10+
   - dependencies
      + "@inertiajs/inertia": "^0.11.1"      <- biblioteca principal do Inertia.js para fazer navegação de páginas e troca de dados entre backend e frontend sem recarregar a página
      + "@inertiajs/inertia-vue3": "^0.6.0"  <- adaptação do Inertia para funcionar com Vue 3 (renderiza páginas, recebe props etc)
      + "axios": "^1.6.4",                   <- cliente HTTP para fazer requisições GET, POST, etc. usado para consumir APIs REST
      + "vue": "^3.5.17"                     <- framework JS para construção de interfaces interativas (Vue 3)
      + "vuetify": "^3.5.10"                 <- biblioteca de componentes UI com Material Design para Vue 3
      + "dayjs": "^1.11.13"                  <- biblioteca leve e poderosa para manipulação e formatação de datas no frontend
__________________________________________________________________________

Ambiente da Máquina Local
   - Node.js: v20.19.3
   - NPM: v10.8.2
   - NVM: 0.0.3 (para gerenciar múltiplas versões do Node.js)
   - PHP: 8.4.1
__________________________________________________________________________

Instruções de Instalação
   - Certifique-se de que o Node.js e npm estão instalados na máquina.
   - Clone o repositório do projeto.
   - Navegue até a raiz do projeto no terminal.
   - Execute (Instalar dependências front-end (Vue, Vuetify, Vite, etc.))
      + npm install (vai gerar o node_modules)
__________________________________________________________________________

Comandos Úteis
   - Iniciar o servidor de desenvolvimento (Vite):
      + npm run dev
   - Gerar build para produção:
      + npm run build
__________________________________________________________________________

Observações
   - O projeto está estruturado para utilizar o Laravel com Inertia e o Vue.js como front-end SPA.
   - A interface é feita com Vuetify, o que facilita a criação de layouts responsivos com design consistente.
   - Banco de dados e servidor web estão dockerizados (PostgreSQL + Nginx + PHP-FPM).
